# Project Brief — The Fish Report

A mobile-first, installable **PWA** for Washington river anglers: live conditions, a
deterministic rig simulator, and a private catch log — usable offline in a dead zone.

**Who it's for:** drift anglers on the Puyallup / White / Carbon / Green / Nisqually.

**Core promise:** honest conditions + a private log. Nothing is fabricated and no spot is
ever published. `productContext.md` explains why that is the identity rather than a feature.

**Detail:** `README.md` — features, file layout, script load order, PWA caching.
